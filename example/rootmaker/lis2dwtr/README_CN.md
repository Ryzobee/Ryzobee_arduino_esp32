# LIS2DW12 加速度计例程

[English](./README.md)

本例程演示如何初始化 Rootmaker 板载 LIS2DW12 三轴加速度计，并通过串口持续输出 X、Y、Z 三个方向的加速度数据。适合用于验证传感器通信状态以及了解加速度数据读取接口的基本用法。

# 功能说明

- 初始化 LIS2DW12 传感器模块
- 周期性读取三轴加速度数据
- 通过串口输出 X、Y、Z 方向原始测量值

# 依赖库

本例程依赖以下 Arduino 库，请先在 Arduino IDE 中安装：

| 名称 | 版本 | 说明 |
|---|---|---|
| [LIS2DW12](https://github.com/stm32duino/LIS2DW12.git) | >= v2.1.1 | 用于支持 LIS2DW12 三轴加速度计的 Arduino 库 |

# 运行说明

- 下载并安装所需依赖库
- 编译并烧录 examples/lis2dwtr/lis2dwtr.ino
- 打开串口监视器，波特率设置为 115200
- 上电后可持续查看 X、Y、Z 三轴加速度数据输出

# 说明

- 本例程仅启用传感器模块，未启用屏幕、LED、按键和电池模块
- 若串口无数据或数据异常，请优先检查传感器初始化是否成功、依赖库版本以及开发板连接状态
