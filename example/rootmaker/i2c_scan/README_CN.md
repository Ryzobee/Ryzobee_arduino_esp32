# I2C 扫描例程

[English](./README.md)

本例程演示如何把 Rootmaker 板上 4 组双针扩展口按 I2C 总线方式依次扫描，并在串口中输出每个端口检测到的设备地址。适合用于排查 I2C 设备连接问题，以及快速确认外设所在的总线端口。

# 功能说明

- 依次初始化 4 组 I2C 端口
- 每组端口使用 `PIN1` 作为 SDA，`PIN2` 作为 SCL
- 扫描每个端口上的 7 位 I2C 地址范围
- 输出每个端口检测到的设备地址和设备数量
- 扫描结束后提示重新复位以再次执行扫描

# 依赖库

本例程使用 Arduino Wire 库和本库提供的引脚定义，无需额外安装第三方 Arduino 依赖库。

# 运行说明

- 编译并烧录 example/rootmaker/i2c_scan/i2c_scan.ino
- 打开串口监视器，波特率设置为 115200
- 上电后，程序会依次扫描 PORT1 到 PORT4 的 I2C 设备
- 若需重新扫描，请按下开发板复位键

# 说明

- 本例程主要用于 I2C 调试和设备排查，不依赖 Rootmaker 外设初始化流程
- 代码中使用 `PORTx_PIN1` 和 `PORTx_PIN2` 映射 I2C 引脚，因为当前板级定义提供的是通用双针端口，而不是 `PORTx_SDA`、`PORTx_SCL` 宏
- 若未发现设备，请优先检查目标模块供电、SDA/SCL 连线、上拉电阻以及设备地址是否正确
