# 屏幕触控例程

[English](./README.md)

本例程演示如何初始化 Rootmaker 板载屏幕与触控功能，并通过点击屏幕中的方块进行简单交互。适合用于验证显示和触控是否正常，以及了解库中屏幕绘制与触摸读取接口的基本用法。

# 功能说明

- 初始化屏幕显示模块和触控功能
- 在屏幕上绘制可点击的红色方块
- 点击方块后随机刷新方块位置
- 点击其他区域时，在触摸点附近绘制绿色像素标记

# 依赖库

本例程基于本库提供的屏幕与触控接口实现，无需额外安装第三方 Arduino 依赖库。

# 运行说明

- 编译并烧录 examples/screen/screen.ino
- 上电后，屏幕会显示一个红色方块和提示文字
- 点击红色方块，方块会跳转到新的随机位置
- 点击其他位置，可看到触摸点留下的绿色标记

# 说明

- 本例程仅启用屏幕模块，未启用 LED、传感器、按键和电池模块
- 若触控无响应或显示异常，请优先检查屏幕初始化、触控硬件状态以及开发板配置是否正确
