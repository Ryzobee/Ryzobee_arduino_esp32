# 电池监控例程

[English](./README.md)

本例程演示如何通过 I2C 与 PY32 电池管理模块通信，在串口输出电池相关信息，并使用板载 RGB LED 作为状态指示。适合用于验证硬件连线、检查电池管理芯片通信状态，以及了解库中电池管理接口的基本用法。

# 功能说明

- 读取电池电压，单位为 mV
- 读取电池电量百分比
- 读取充电状态：未充电、充电中、充电完成
- 读取电池管理模块固件版本
- 读取和设置按键开机时间与关机时间
- 配置定时唤醒
- 发送关机指令

# 硬件连接

| ESP32S3 | PY32 |
|---------|------|
| GPIO41 (SDA) | PB4 (I2C_SDA) |
| GPIO40 (SCL) | PB3 (I2C_SCL) |

# I2C 地址

- PY32 从机地址：`0x73`

# 电量说明

本例程中的电量百分比不是简单线性换算，而是基于单节锂电池常见放电曲线进行拟合计算。

- 100% 电量对应约 4200 mV
- 0% 电量对应约 3450 mV
- 3450 mV 到 4200 mV 之间的电量采用分段曲线拟合估算

这意味着程序输出的电压值是当前测得的电池电压，而显示的百分比是根据电压进一步换算得到的估算值。由于电池负载、采样波动和滤波处理的影响，电压与百分比之间不会始终严格一一对应。

# 使用说明

- 上电后，程序会初始化 Rootmaker 的 LED、按键、电池外设和 PY32 电池管理模块
- 若 I2C 通信正常，串口会输出固件版本、电池电压、电量百分比、充电状态以及按键配置时间
- 电量变化时，RGB 灯颜色会随电量变化，并触发闪烁提示
- 按下按键可停止闪烁提示

# 说明

- 本例程依赖硬件上的 PY32 电池管理模块正常工作
- 使用 `board.maker.begin(true, false, true, true)` 选择需要启用的板载外设；屏幕通过独立的 Yoke 外设对象初始化。
- 若串口没有输出有效电池信息，请优先检查供电、I2C 连线和从机地址是否正确
- 若需要让输出电压与电量计算使用完全一致的数据源，可在示例中改用滤波后的电压接口
