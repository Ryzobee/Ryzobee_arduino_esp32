# 按键输入例程

[English](./README.md)

本例程演示如何使用 Rootmaker 板载按键检测不同的按键事件，并通过串口输出事件类型。适合用于验证按键输入是否正常，以及了解库中按键事件接口的基本用法。

# 功能说明

- 初始化 Rootmaker 板载按键模块
- 轮询按键事件状态
- 识别并输出短按、长按、双击和长按持续触发事件

# 依赖库

本例程基于本库提供的按键接口实现，无需额外安装第三方 Arduino 依赖库。

# 运行说明

- 编译并烧录 examples/btn/btn.ino
- 打开串口监视器，波特率设置为 115200
- 按下板载按键后，可在串口中查看对应事件输出

# 说明

- 本例程仅启用按键模块，未启用屏幕、LED、传感器和电池模块
- 若串口没有输出，请优先检查开发板型号、串口波特率以及按键硬件是否正常
